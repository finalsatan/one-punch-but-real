# 风格串（Style Anchor）

> **项目级共享资产**：`grid-storyboard`（九宫格分镜）、`character-sheet`（角色参考图）、`location-sheet`（场地参考图）三个技能共用本文件。
> 本项目**只有一个风格档**。生图 prompt 的 `Style:` 字段**只能**从本文件取值，禁止现场改写或自创；九宫格亦**只有一行 `Style:`**，不得拆成九行 `Style — Panel N:`。
> （文件名 `画风档位串.md` 为历史保留——本项目曾区分「日常档 / 写实档」双档，该结构已作废，见下方「历史沿革」。）

## 唯一风格串（Style Anchor）

> **来源**：项目根 `素材/画风/画风约束.md` 原文，逐字复制，**不得改写**。
> 若该文件被修改，本段须同步更新为最新原文。
> **目标参照**：`素材/画风/画风参考.png`——本串即对该图的文字化描述。全项目所有角色都向这个画风靠拢。

```
High-quality polished modern 2D anime key-visual illustration, hand-drawn 2D cel-animation artwork, similar to official TV anime key visual art. Clean precise medium-weight black line art, clearly visible on every edge including hair, clothing, props and background, never softened away, never blurred, never replaced by airbrushed gradients. Hard-edged flat two-tone cel shading on skin and hair with crisp shadow boundaries, no airbrushed gradients on faces, no soft blur on skin. Fully illustrated 2D painted backgrounds with believable depth and perspective, built from flat color planes and crisp hand-drawn linework, with only minimal hard-edged two-tone cel shading and no soft gradients on walls, floors or furnishings. Natural believable color palette, not oversaturated, not flat. Refined facial rendering with subtle eye highlights, clean line art and nuanced expressions. Professional anime-production-level polish and consistency across every panel. Hand-drawn 2D illustration only, painted cel look, 2D animation artwork.
```

**用于**：九宫格 `Style:` 行 · 角色参考图 `Style:` 行 · 场地参考图 `Style:` 行。三段共用同一串，唯一一份原文。

**只统一渲染风格，不统一体型比例。** 各 IP 角色保留自身原体型比例（小新仍是矮胖 5 岁、哆啦A梦仍是圆润机器猫、比斯基伪装仍是小女孩）；本串只管描线 / 上色 / 光影画法。

## 参考图上传策略

出图时按下列规则决定同批上传哪些参考图。**参考图权重压过文字，传错图比写错字更致命。**

| 参考图 | 上传？ | 作用 | 说明 |
|---|---|---|---|
| `素材/画风/画风参考.png` | ✅ **任何出图一律上传** | 风格锚点（定画风） | 它是本风格串的目标，是唯一且必传的风格锚点 |
| `素材/角色/*-三视图.png` | ✅ 上传 | 定长相与体型比例 | 该场出镜角色对应那张；背景剪影角色也要传 |
| `素材/场地/*-场地设定图.png` | ⛔ **暂不上传** | 原本用于定空间 | **现有两张为 CG/3D 渲染空间图（体积光 + 环境光遮蔽 + 地板反射），是九宫格空间 3D 感的直接注入源。** 空间改由 `素材/场地/场地锚点表.md` 的英文布局串 + `layout / light / palette` 字段锁定 |

**场地参考图恢复上传的条件**：重出一版严格 2D 平涂的场地设定图后（另开方案）。在此之前，九宫格交付文件元信息的场地行**不得出现 `.png` 路径**，否则会被 `image-gen` 自动上传。

## 反 3D 负向词表（Negative 追加段）

三份 Prompt 模板（`grid-prompt-template.md` / `character-sheet-prompt-template.md` / `location-sheet-prompt-template.md`）的 `Negative:` 段**必须**在原有文本之后追加下面这一段，逐字照抄，不增不删：

```
no CGI, no computer-generated look, no videogame cutscene look, no clay or plastic render, no ray-traced lighting, no global illumination, no ambient occlusion, no volumetric light shafts, no lens flare, no depth of field, no bokeh, no photographic blur, no specular PBR highlights, no metallic PBR shading, no subsurface scattering, no soft airbrush rendering on skin, no airbrushed gradient replacing line art, no missing or faded outlines, no 3D-looking background, no photoreal materials
```

> `no 3D render` 与 `no photorealistic or live-action rendering` 已存在于原有 Negative 文本，**不重复追加**。

**为什么需要这一段**：《画风参考.png》是精致 key visual，「精致」与「CG 渲染」在模型语义里相邻。原有 Negative 只有 `no 3D render` 一个词，挡不住「高质量渲染感动画」（软笔刷阴影 / 体积光 / 景深）——模型并不认为自己在做 3D，它认为在做「精致的 2D 动画」，于是 `no 3D render` 完全不触发。必须以「具体渲染技术名」逐条封锁。

## 锁定 vs 解锁（全项目通用）

**锁定（任何情况下都不得改变，写进 prompt 的 `Consistency:` 段）**

> 脸型 · 发型 · 发色 · 瞳色 · 服装造型与配色 · 体型比例 · 场景空间结构 · 光源方位与时相 · 整体色彩基调

其中「场景空间结构 · 光源方位与时相 · 整体色彩基调」三项以 `素材/场地/场地锚点表.md` 与场地锚定串为准。

**允许变化**

> 动作 · 姿态 · 表情 · 景别 · 机位角度

---

## 禁止出现的风格词

以下词**不得**出现在生图 prompt 中：

```
photorealistic, live-action, photographic, sequence photography, film still,
3D render, CGI, octane render, unreal engine, ray-traced lighting, global illumination,
ambient occlusion, volumetric light, depth of field, PBR, subsurface scattering,
rendered highlights, realistic environmental lighting, cel-shaded 3D, digital painting over 3D base,
oversaturated, neon, heavy bloom, chromatic aberration,
sketch, rough draft, unfinished, watermark, signature
```

> **例外**：Negative 段中作为**否定词**出现的形式（`no photorealistic or live-action rendering` / `no 3D render` / 反 3D 负向词表内的各项 / `no oversaturated colors`）属必要守卫，**必须保留**，不算违规。上表禁的是**正向描述**用词。

`8K` 亦禁止（只写 `high detail`）——多数模型输出 ≤2048px，写高分不构成约束。

## 历史沿革

本项目曾使用**双档**结构：

| 旧档位 | 旧风格串 | 处置 |
|---|---|---|
| 日常档（Q 版） | `clean-line rounded Q-style anime, simplified shapes, flat cel colors…` | **已删除**。它与《画风参考.png》的精致 2D key-visual 风格互斥；九宫格默认取此档，正是「出图风格与参考图不一致」的直接原因 |
| 写实档（讲解节拍） | 含 `soft rendered highlights` / `subtle gradient shadows` / `realistic environmental lighting` / `naturalistic semi-realistic anime proportions` | **已改造为本文件的唯一风格串**（删除上述 4 处渲染/比例措辞，新增描线强制语与 2D 锁定语） |

**作废的配套机制**：

1. 剧本 `[画风切换为写实线条]` 标记**作废**——技能识别该标记但**忽略**，不再据此切档。
2. 大纲「画风双层」系列视觉签名**作废**——全系列统一为上述唯一 2D 画风。
3. `grid-storyboard` 调用参数 `写实格=` / `全日常` **作废**。
4. `image-gen` 的 `--variant 日常|写实` **deprecated**（新交付文件 ③ 段为单块，不需要传）。
5. 角色 / 场地交付文件的 `③-A 日常档` + `③-B 写实档` 双块结构 → **单一 ③ 段**。
6. 锚点表 `ref: 日常=…；写实=…` → `ref: <单一路径>`。
