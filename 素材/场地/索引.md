# 场地参考图索引（Location Sheet Index）

> **作用**：场地参考图的生成进度看板 + 反向引用表。空间锚定串只存在于 `素材/场地/场地锚点表.md`，本表**不复制**锚定串，避免双写漂移。
> **上游生产者**：`.pi/skills/location-sheet/` 技能（生成 prompt）→ 使用者粘贴出图 → 回写本表与锚点表 `ref:` 字段。
> **下游消费者**：`.pi/skills/grid-storyboard/` 技能（九宫格元信息「需同批上传的参考图 · 场地」，只登记场地名与镜号，不登记路径）。

## 出图时的上传顺序

1. **角色参考图**（该场出镜角色）→ 定长相
2. `素材/画风/画风参考.png` → 定画风（必传）
3. 九宫格 prompt → 出 9 格

> **跨界拳馆训练区已换新版 2D 设定图，可上传**；片头黑舞台仍为 CG 版，暂不上传。
> 原说明：现有两张为 CG 渲染空间图，会注入 3D 感，**暂不进入出图链路**。空间改由 `素材/场地/场地锚点表.md` 的英文布局串 + `layout / light / palette` 锁定。详见 `素材/画风/画风档位串.md`「参考图上传策略」。

## 回写流程（出图后）

1. 把出好的 PNG 放到 `素材/场地/`，按 `<场地名>-场地设定图.png` 命名（已生成的旧文件保留 `-日常档-` 历史文件名）。
2. 更新锚点表 `ref:` 字段：`素材/场地/<场地名>-场地设定图.png`。
3. 更新本表对应行的图片路径与状态为 `已生成（已回写 ref）`。
4. 若该场地已被已有分镜引用 → 把对应分镜 ④ 自检里的 `参考图风险` 从「中」降为「低」。
