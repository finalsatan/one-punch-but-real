# 角色音色调研（现成角色音色 + 免费方案）

> 目标：解决「MiniMax 声音设计出来的音色和原作角色对不上」的问题。
> 调研日期：2026-10-22；试听音频已下载在 `素材/音色/试听-fish/`。

## 一、结论（TL;DR）

1. **现成的原角色音色确实有**，在 **Fish Audio**（fish.audio）的公共音色库里：社区用原作配音训练的 TTS 模型，用 `reference_id` 直接调用，音色即该角色的原声。
2. Fish 官方 API 的 **`s2.1-pro-free` 模型按公平使用计费 $0**，能力与付费版 `s2.1-pro` 相同（83 语种、支持方括号风格指令），适合本项目这种小体量。
3. **中文资源分布不均**：小新、哆啦A梦、旁白 有高质量中文音色；**埼玉、龙卷、比斯基 没有中文模型**，只有日/英/西/葡版（跨语种说中文会带口音，需试听确认）。
4. **都不花钱**：Fish 免费模型只需注册个免费账号；不想注册就用 HF Space 零样本克隆（已实测跑通，见第二节）。
5. 已在工程里接好三个开关：`fish.py` + `voices_fish.json`（Fish）、`indextts.py` + `voices_hf.json`（HF Space 免费克隆）、原 MiniMax/edge-tts 兜底；`tts.py` 按 `TTS_PROVIDER` 与 key 是否存在自动选路。

## 二、零成本方案（2026-10-22 实测）

能拿到「原角色音色」又**一分钱不花**的，只有三条路，实测情况：

| 方案 | 费用 | 要注册吗 | 角色音色 | 实测结果 |
|---|---|---|---|---|
| **Fish `s2.1-pro-free`** | **$0**（官方口径：Fair Use 下不限量，活动期写的是「到 2026-11-30 免费」） | 免费注册 + 邮箱验证，不用绑卡 | ✅ 上表所有 reference_id 直接可用 | 代码已接好，**差一个免费 key**；并发 5，整集够用 |
| **HF Space `IndexTeam/IndexTTS-2-Demo`**（零样本克隆） | **$0** | 不填 token 也能跑（匿名） | ⚠️ 需自备 8–15 s 参考音频（Fish 的试听 mp3 正好能当参考） | **已跑通**：匿名 3 次/IP 后提示超 ZeroGPU 额度；填免费 HF token 走每日免费额度；串行，约 5–6 s/句 |
| **edge-tts**（现有兜底） | $0 无限 | 不用 | ❌ 只有通用音色 | 一直在库，只是不像 |
| MiniMax 声音设计（现方案） | 付费 | 有 | ⚠️ 神似 | 现 key 余额 0，`1008 insufficient balance` |

结论：
- **要批量 + 像 → Fish 免费模型**（唯一「$0 + 现成角色音色 + 可脚本批量」的组合，代价只是注册个免费账号）；
- **要绝对零账号 → HF Space 零样本克隆**，已接好：`TTS_PROVIDER=indextts python3 tts.py`（记得先 `pip install gradio_client`）；
- 全网没有「不用注册 + 现成 IP 角色音色 + 批量调用」的东西：这类音色都是社区上传的，各平台都要账号鉴权。

已经用免费路线产出的试听样本（3 句，IndexTTS-2 拿 Fish 试听音频当参考克隆出来的）：
`素材/音色/试听-免费方案/小新-indexTTS2-参考自Fish试听.wav`（1.6s）、`埼玉-…wav`（2.9s）、`龙卷-…wav`（2.4s）。

## 四、缺中文原声时的三条补齐路线

1. **自行克隆原作中配**（最贴近，也最省事）
   取该角色 10–30 秒干净中配音频 → 上传到 Fish「Voice Cloning」/ MiniMax 声音复刻 / Noiz 克隆，得到自己的 voice_id，填进 `voices_fish.json`。
   素材来源：B 站/油管的**中配片段**。注意：这一步等于把别人的表演做成音色模型，仅适合内部试作，公开发布有风险（见第五节）。
2. **社区通用中文音色**（零准备，合法安全）：即上表「中文替代」那几行。
3. **继续用 MiniMax 声音设计**（现有 `design_voices.py`）：把 `timeline.VOICES[*]['design']` 的措辞改得更具体（加年龄/音域/口音/气声/语速/咬字特征），比换模型便宜，但永远只是「像」，到不了「是」。

## 五、接入方式（已改好）

### 5.1 免费首选：Fish `s2.1-pro-free`

1. 注册 https://fish.audio/auth/signup → https://fish.audio/app/api-keys 建 key。
2. 写进环境变量或文件（与 MiniMax 同风格）：
   ```bash
   export FISH_API_KEY=xxxx        # 或 echo xxxx > ~/.config/fish/api_key
   ```
3. 选音色：改 `成片/EP1/工程/voices_fish.json`（角色 → reference_id）。
4. 重配整集：
   ```bash
   rm -rf 成片/EP1/工程/build/voice && python3 成片/EP1/工程/tts.py
   ```
   `tts.py` 会打印 `provider: fish`，再照常 `build.sh` 出片。只重配某几句就只删对应 `build/voice/<镜号>_<序号>.wav`。

### 5.2 零账号备选：HF Space IndexTTS-2 零样本克隆

```bash
pip install gradio_client        # 系统 python 装了 PEP668 的话：python3 -m venv .venv && .venv/bin/pip install gradio_client
# 可选：export HF_TOKEN=hf_xxx   （免费 HF 账号的 token，匿名只能跑 3 次/IP）
TTS_PROVIDER=indextts python3 tts.py
```

- 参考音频写在 `voices_hf.json`（角色 → 8~15 s 音频路径），现在指向 `素材/音色/试听-fish/` 里的原声试听；
- 强制串行（Space 单实例，`Semaphore(1)`），整集约 60 句要排队跑十几分钟；
- 免费 ZeroGPU 额度按天算，跑整集大概率不够，适合**改几句、试音色**。

### 5.3 Fish 底层请求等价于：

```bash
curl -X POST https://api.fish.audio/v1/tts \
  -H "Authorization: Bearer $FISH_API_KEY" -H "Content-Type: application/json" \
  -H "model: s2.1-pro-free" \
  -d '{"text":"[惊讶地] 这不可能是真的吧？","reference_id":"e71bbb278a8944cfbdc8e8373c4c0fd4",
       "format":"mp3","mp3_bitrate":128,"sample_rate":44100,
       "prosody":{"speed":0.95,"volume":0,"normalize_loudness":true}}'
```

要点：
- **风格指令**用方括号写在台词里（`[懒洋洋地]`、`[吼]`、`[小声嘀咕]`…），不限于固定 8 种情绪，比 MiniMax 的 `emotion` 枚举自由得多，正好治「语气平」这个毛病。工程里 `fish.STYLE` 已把现有 `EMOTION` 映射过去。
- 支持 `reference_id` 传数组做**多角色对白**合成（本项目按句生成，用不上）。
- 并发上限：Starter 档 5 并发（`tts.py` 现有 `Semaphore(4)` 正好）。

## 六、风险与合规（重要）

- 这些公共模型是**对真人配音演员声音的克隆**（小新=日配/中配声优、埼玉=古川慎等）。在中国涉《民法典》第 1023 条声音权益，在日本涉声优的パブリシティ権，同时平台可能因 IP 方投诉下架模型（Fish 有 DMCA 流程，页面字段 `dmca_taken_down`）。
- 本项目是教学向、会公开发布 → 建议：
  - **内部试作/预览**：随便用社区模型，效果最好；
  - **正式发布**：换「中文替代」音色或授权音色（保持 `voices_fish.json` 一键切换，重配成本只有几分钟）；
  - 片尾/简介标注「AI 合成语音」，降低争议。
- 原片中配音频**不要直接剪进成片**：时长/口型/上下文都对不上，且是明摆着的侵权素材；它只适合当克隆参考。

### 重配后语速（vs 旧 MiniMax，已调参到当前版本）

第二版已把 `timeline.VOICES` 里的 `旁白 speed=0.9`、`龙卷 speed=0.95`（第一版是 1.0 / 1.05）。

| 角色 | 句数 | 旧 MiniMax | Fish 第一版 | Fish 调速后 |
|---|---|---|---|---|
| 旁白 | 4 | 18.04 s | 10.54 s | **11.67 s** |
| 龙卷 | 6 | 5.10 s | 7.59 s | **8.89 s** |
| 小新 | 3 | 4.54 s | 5.55 s | 5.55 s |
| 埼玉 | 4 | 9.50 s | 12.11 s | 12.11 s |
| 哆啦A梦 | 2 | 9.95 s | 7.13 s | 7.13 s |

要点：
- Fish 的 `prosody.speed` 生效但不是严格线性，**同一句重跑时长会飘**（2-03 第一版 2.61 s，降速后重跑得 2.78 s，第二次重跑才稳定）；觉得不对劲就删对应 wav 重跑。
- 长句仍可能超过镜头长（如「十秒法则…」5.78 s / 镜头 4.0 s），`render.py` 会自动拉长镜头吸收，不用手改 `dur`。
- 要再调只需改 `timeline.VOICES[角色]['speed']` + 删对应 `build/voice/<镜号>_<序号>.wav` 重跑。
