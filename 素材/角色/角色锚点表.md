# 角色锚点表（Character Anchors）

> **项目级共享资产**：`grid-storyboard`（九宫格分镜）与 `character-sheet`（角色参考图）两个技能共用本表。
> 生图 prompt 正文涉及任何角色时，**必须**使用本表的英文锚定串，**禁止**只写角色名或 IP 名。

## 格式规范

```
<中文名> | <IP 官方英文名> | hair: <发型+发色> | eyes: <瞳色> | outfit: <服装+配色> | build: <体型+年龄感> | prop: <标志性道具> | ref: <路径或「未生成」>
```

英文锚定串写法（生图 prompt 里直接用这一行）：

```
Shinnosuke Nohara (Crayon Shin-chan): short black hair with 5 spiky tufts, thick black caterpillar eyebrows, small black oval eyes, red T-shirt, yellow shorts, chubby 5-year-old body proportions
```

写入原则：
- 一个角色一行，`|` 分隔字段，**字段顺序固定**（hair → eyes → outfit → build → prop → ref）
- 缺失信息写 `n/a`，不留空
- 生图 prompt 用「英文名 + 括号内 IP 英文名 + 外观描述」的组合形式，确保模型既能识别又能落定外观
- `ref:` 字段登记角色参考图（三视图设定表）路径，格式 `<路径>`；未生成写 `未生成`
- 参考图由 `character-sheet` 技能产出，见 `素材/角色/索引.md`

## 道具状态锚点

道具的**状态变化**也是连续性锚点，同一场景内若道具再次出现，必须保持已发生变化的状态。

| 道具 | 首次出现 | 状态变化 | 后续格要求 |
|---|---|---|---|
| 哑铃杆 | EP1 场景5 | 被比斯基轻轻一捏 → **弯折** | 后续格若出现，须保持已弯状态 |
| 训练假人底座弹簧 | EP1 场景2 | 被掀飞后**弹回原位站好** | 后续格若出现，须为已归位、站姿 |
