# 角色参考图索引（Character Sheet Index）

> **作用**：角色参考图的生成进度看板 + 反向引用表。锚定串只存在于 `素材/角色/角色锚点表.md`，本表**不复制**锚定串，避免双写漂移。
> **上游生产者**：`.pi/skills/character-sheet/` 技能（生成 prompt）→ 使用者粘贴出图 → 回写本表与锚点表 `ref:` 字段。
> **下游消费者**：`.pi/skills/grid-storyboard/` 技能（九宫格元信息「需同批上传的参考图 · 角色」）。

---

## 出图时的上传顺序

1. **角色参考图**（该角色的那张）→ 定长相
2. `素材/画风/画风参考.png` → 定画风（必传）
3. 九宫格 prompt → 出 9 格

> **全项目只有一个风格档**：角色参考图不再分「日常档 / 写实档」，一个角色只有一张。

## 回写流程（出图后）

1. 把出好的 PNG 放到 `素材/角色/`，按 `<角色名>-三视图.png` 命名（已生成的旧文件保留 `-日常档-` 历史文件名）。
2. 更新锚点表 `ref:` 字段：`素材/角色/<角色名>-三视图.png`。
3. 更新本表对应行的图片路径与状态为 `已生成（已回写 ref）`。
4. 若该角色已被已有分镜引用 → 把对应分镜 ④ 自检里的 `参考图风险` 从「中」降为「低」。
