# 角色参考图提示词生成（Character Sheet）

## 概述

把一个**角色**（如 `小新`、`埼玉`、`龙卷`）转成一份**角色参考图交付文件**，包含：

1. 元信息（角色 / IP / 比例 / 版式 / 背景 / 表情小样 / 标志道具 / 输出路径 / 生成状态）
2. 锚点复核表（九个字段的值与来源 + 背面视角设计）
3. 可直接复制的**英文三视图生图 Prompt**（单一 ③ 段）
4. 自检清单（14 项）

**为什么要有这一步**：九宫格是**一次性把同一角色渲染 9 遍**，跨 IP 混编时只要一格漂移整张就废。纯文字锚定串能压住外观描述，但压不住「模型对同一角色在不同格里的自由发挥」。角色参考图是**图片锚点**，比文字锚点强得多，且一张设定图可跨集复用。

**本 skill 不出图。** 只产出提示词文本，出图由使用者把它粘贴到工具完成。

> **本项目的出图执行器**：`.pi/skills/image-gen/`。它直接读本 skill 产出的交付文件，自动抽第 ③ 段 prompt 与第 ① 段登记的角色参考图，同批提交给 tokenflux 出图（`image-gen` 会自行处理 `/images/edits` 的多图上传）。手工粘贴到 即梦 / Midjourney / GPT / Nano Banana 等工具仍然可用——`image-gen` 是可选路径，不是替代。

**开始时宣布：** 「我正在使用 character-sheet 技能生成角色参考图提示词。」

**出图时的上传顺序**（写进交付文件，供使用者照做）：
1. **角色参考图**（该角色的那张）→ 定长相
2. `素材/画风/画风参考.png` → 定画风
3. 九宫格 prompt → 出 9 格

## 铁律（违反即失败）

1. **一张图只画一个角色。** 严禁同图出现第二人物 / 宠物 / 群众。
2. **画面零文字。** 含 `front` / `side` / `back` 视角标签、色值、箭头、尺寸线、编号、水印、签名。
3. **三视图规范固定**：正 / 侧 / 背三个全身视角，同比例、同站姿；不得自由发挥视角、不得加第四视角。
4. **这不是九宫格。** 无分格线、无边框、无 grid、无漫画分镜结构；六个图形只靠留白分隔。
5. **纯中性背景。** 不得出现场景、环境、地面线、投影渐变。
6. **③ 段只允许一段 prompt。** 全项目已合并为单一 2D 画风，不再有「日常档 / 写实档」双块；风格由唯一风格串统一决定。
7. **锁定的角色设计属性任何情况下都不得改变**，**含体型比例**。Q 版角色（小新 / 哆啦A梦 / 比斯基伪装 / 训练假人）始终保持原体型，只统一描线 / 上色 / 光影画法。
8. **禁止把写实照片风当风格用。** 风格串只能取 `素材/画风/画风档位串.md` 的**唯一风格串**；禁止作为**正向描述**出现 `photorealistic / live-action / sequence photography / CGI / 3D render`（Negative 段中作为否定词的 `no photorealistic or live-action rendering`、反 3D 负向词表各项属例外，必须保留）。
9. **禁止把 8K 当硬约束。** 只写 `high detail`。
10. **标志性道具只取锚点表登记的**，不得加戏。

## 工作流

### 1 解析调用参数

调用形态（`/skill:character-sheet` 后的参数）：

| 输入 | 行为 |
|---|---|
| `小新` | 直接生成 → `素材/角色/小新.md` |
| `EP1` | **列出** EP1 全部出场角色与各自 `ref:` 状态，等使用者选择。**不得自行替选** |
| 无参数 | 扫描 `素材/角色/角色锚点表.md` + `剧本/EP/*.md`，列出「有出场但 `ref:` 为未生成」的角色 |
| `档=日常` / `档=写实`（**已作废**） | 传入即忽略。全项目已合并为单一 2D 画风，③ 段只有一段 |
| `比例=3:2` | 覆盖默认 16:9 横版 |
| `回写` | 生成后直接回写锚点表 `ref:` 与 `素材/角色/索引.md`；**默认只产交付文件 + 主动询问** |

- 角色名以锚点表 `### <中文名>` 小节标题匹配；用中文名做文件名。
- 角色在锚点表中不存在 → 按锚点表「格式规范」现场生成锚点，并在交付文件末尾**主动询问是否追加进锚点表**。

### 2 读取素材（必读）

1. `素材/画风/画风约束.md` → **唯一风格串**的**权威源**。
2. `素材/画风/画风档位串.md` → **唯一风格串** + 参考图上传策略 + 反 3D 负向词表，**逐字引用**，不得改写。
3. `素材/角色/角色锚点表.md` → 角色锚定串与 `ref:` 状态。
4. `剧本/EP/*.md` + `剧本/大纲/*.md` → 取该角色 3 个标志性表情与标志道具的语境依据。

### 3 锚点复核

- 逐字段核对 `hair / eyes / outfit / build / prop`；缺字段现场补，并**询问是否回写锚点表**。
- 补齐英文锚定串中缺失的具体信息（如「pink and white frilled dress」是否含蕾丝边、领口样式）。
- **显式写出背面视角的发型形状与服装设计**（防止模型在背面视角自由发挥）。
- 从剧本取 3 个**标志性表情**（如小新：笑嘻嘻 / 怀疑撇嘴 / 得意），写入 `Expressions:` 行。
- 无脸 / 道具型角色（训练假人）**无表情行**，改用 3 个细节 / 状态小样（见下）。

### 4 生成交付文件

路径：`素材/角色/<角色名>.md`（`素材/角色/` 目录首次运行时创建）。

结构模板见 `assets/character-sheet-template.md` 与 `assets/character-sheet-prompt-template.md`，四段固定顺序：

1. **元信息**
2. **锚点复核表**（九个字段的值 + 来源，含背面视角设计）
3. **英文 Prompt**（**单一代码块** `## ③ 英文 Prompt`；已无档位，不得出现 ③-A/③-B 双块）
4. **自检清单**（14 项）

### 5 回写登记

询问后（或带 `回写` 参数）执行：

1. 锚点表 `ref:` 字段 → `日常=<路径>；写实=<路径>`
2. `素材/角色/索引.md` 对应行状态更新
3. 若该角色已被已有分镜引用，把对应分镜 ④ 自检里的 `参考图风险` 从「中」降为「低」

### 6 自检（必须执行，结果写进交付文件第 ④ 段）

逐项写出 `[x]`/`[ ]` 与依据：

1. **单一角色**：全图只有 1 个角色，无第二人物 / 宠物 / 群众
2. **版式**：上排正 / 侧 / 背三视角全身、同比例同站姿；下排 3 个表情小样（无脸 / 道具型角色按例外处理）
3. **画面零文字**：无视角标签、无箭头、无色值、无编号、无水印、无签名
4. **无分格线 / 边框 / grid**：未画成九宫格或漫画分镜，六个图形仅靠留白分隔
5. **背景**：纯中性浅灰平涂，无场景 / 环境 / 地面线 / 投影渐变
6. **锚定串完整**：九个字段逐项落地，无「只剩角色名」
7. **跨视角一致**：背面视角的发型形状与服装设计已在 prompt 中显式声明
8. **③ 段为单一块**：只有一个代码块，未出现 ③-A/③-B 双块或第二个风格串
9. **`Consistency:` 含体型比例锁定语**：Q 版角色仍保持原体型比例，未被归一化、未被改成 chibi
10. **比例声明**：全图 16:9（或调用参数指定值），只声明一次，未与九宫格比例混写
11. **Negative 段完整照抄**（**含反 3D 负向词表**），未增删
12. **禁用词检查**：无 `photorealistic / live-action / sequence photography / CGI / 3D render / 8K`（Negative 否定形式除外）
13. **道具克制**：只带锚点表登记的标志性道具
14. **参考图登记已回写**锚点表 `ref:` 与 `素材/角色/索引.md`（若使用者确认）

末尾追加：
```
风格风险：低 / 中（无画风参考图）
参考图风险：低（本文件即参考图源头）
```

## 反模式黑名单（禁止回归）

| # | 反模式 | 处理 |
|---|---|---|
| 1 | 一张图塞两个角色做「对照」 | 铁律 1；多角色各自一图 |
| 2 | 画面里写 `front / side / back` 标签 | 铁律 2；视角映射写进 ① 元信息（人可读区） |
| 3 | 画成九宫格 / 漫画分镜 | 进 Negative（`no panel borders / no manga panel layout / no storyboard`） |
| 4 | 加场景背景让图更好看 | 进 Negative（`no scene background`） |
| 5 | 背面视角发型 / 服装自由发挥 | ② 锚点复核表 + prompt `Back-view design:` + 自检 7 |
| 6 | 顺手把 Q 版角色改成半写实人体 / 归一化头身比 | 铁律 7 + 自检 9 |
| 7 | 重新引入第二段 prompt / 第二个风格串 | 铁律 6 + 自检 8 |
| 8 | 参考图比例写成 9:16 | 自检 10 拦截（参考图默认 16:9 横版，与九宫格 9:16 无关） |
| 9 | 把参考图路径写进 prompt 正文 | 禁止；路径只进交付文件元信息（人可读区） |

## 常见借口对照

| 借口 | 为什么无效 |
|---|---|
| 「一张图放全角色更省事」 | 角色一多会互相污染发型 / 配色，参考图就失效了。一人一图。 |
| 「画面里标个 `front/side/back` 更好读」 | 文字会跟着模型一起被画进图里，参考图本身就成了噪声源。视角映射写在交付文件里给人看。 |
| 「写实档干脆按半写实人体画」 | 项目锁定体型比例，小新必须还是矮胖 5 岁。本风格串只统一描线 / 上色 / 光影画法。 |
| 「加个拳馆背景更有氛围」 | 背景会污染九宫格出图时的空间判读，参考图必须纯中性背景。 |
| 「双档各写各的锚点更灵活」 | 全项目已合并为单一 2D 画风，第二档已作废。③ 段只允许一段 prompt。 |
