# 场地参考图交付文件模板

> 这是 `location-sheet` 技能生成交付文件时的骨架。`<<...>>` 为占位符，运行时替换为实际内容。
> 交付文件写入 `素材/场地/<场地名>.md`，四段顺序不可调换。
> **全项目只有一个风格档**：③ 段只有一段 prompt，`Style:` 只写一行。

## ④ 自检清单

逐项 `[x]` / `[ ]` + 依据：

- [ ] 1. 单一场地：全图只画 1 个场地空间，无跨场景拼贴
- [ ] 2. 版式：实景空间型 = 上排三机位 + 下排居中俯视布局图；抽象舞台型 = 主视角 + 反向机位（按例外处理）
- [ ] 3. 空场：画面内无任何角色 / 人形剪影 / 群众 / 宠物（prompt 与 Negative 双处声明）
- [ ] 4. 画面零文字：无机位标签、无箭头、无尺寸线、无编号、无水印、无签名
- [ ] 5. 无分格线 / 边框 / grid：各视图仅靠均匀留白分隔
- [ ] 6. 机位自洽（不越轴）：三机位的轴线、入口方位、纵深关系互相一致
- [ ] 7. 俯视布局图与三机位一致：固定陈设位置与三机位所见逐件吻合（抽象舞台型不适用）
- [ ] 8. 光照一致性：光源方位与时相在全部视图里相同；俯视图以阴影方向表达同一光位
- [ ] 9. 锚点字段完整：九个字段逐项落地，无「只剩场地名」
- [ ] 10. ③ 段为单一块：只有一个代码块，未出现 ③-A/③-B 双块或第二个风格串
- [ ] 11. 风格切换未改空间结构：材质 / 布局 / 光位 / 配色锁定不变
- [ ] 12. 比例声明：全图 16:9（或调用参数指定值），只声明一次，未与九宫格 9:16 混写
- [ ] 13. Negative 段完整照抄（含反 3D 负向词表），未增删
- [ ] 14. 禁用词检查：无 `photorealistic / live-action / sequence photography / CGI / 3D render / 8K`（Negative 否定形式除外）
- [ ] 15. 场地参考图登记已回写锚点表 `ref:` 与 `素材/场地/索引.md`（若使用者确认）；`上传策略` 行已注明本阶段不上传
