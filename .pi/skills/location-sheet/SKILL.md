# 场地参考图提示词生成（Location Sheet）

## 概述

把一个**场地**（如 `跨界拳馆训练区`、`片头黑舞台`）转成一份**场地参考图交付文件**，包含：

1. 元信息（场地 / 英文名 / 场地类型 / 比例 / 版式 / 轴线约定 / 固定陈设 / 光源 / 空场声明 / 输出路径 / 生成状态）
2. 空间锚点复核表（九个字段的值与来源 + **各机位可见内容**专项表）
3. 可直接复制的**英文场地设定图生图 Prompt**（单一 ③ 段）
4. 自检清单（15 项）

**为什么要有这一步**：九宫格里「拳馆地垫拼缝」「远角」「入口」「顶光偏左前」「场地被中轴划为左右半」这些空间信息全靠分镜文字在重复描述——这是跨 9 格、跨场景、跨集最易漂移的部分，且比角色漂移更隐蔽（一格空间结构变了，整格叙事就废了）。场地参考图是**图片锚点**，能一次钉死轴线、固定陈设位置与光位。

**本 skill 不出图。** 只产出提示词文本，出图由使用者把它粘贴到工具完成。

**开始时宣布：** 「我正在使用 location-sheet 技能生成场地参考图提示词。」

**出图时的上传顺序**（写进交付文件，供使用者照做）：
1. **角色参考图**（该场出镜角色）→ 定长相
2. `素材/画风/画风参考.png` → 定画风
3. 九宫格 prompt → 出 9 格

> **注意**：本 skill 产出的场地设定图**暂不进入出图链路**（现有两张为 CG 渲染空间图，会注入 3D 感）；空间改由场地锚定串锁定。详见 `素材/画风/画风档位串.md`「参考图上传策略」。

## 铁律（违反即失败）

1. **一张图只画一个场地。** 严禁同图出现两个空间 / 跨场景拼贴 / 时间跳变。
2. **空场。** 画面内**不得出现任何角色**（含人物、人形剪影、群众、宠物）。角色外观由 `character-sheet` 负责，本技能只出空间。固定陈设（训练假人、装备箱等）**不算角色**，属场地陈设，可以出现。
3. **画面零文字。** 含机位标签（`main view` / `reverse`）、尺寸线、箭头、编号、色值、水印、签名。
4. **版式固定**，由锚点表 `type:` 决定，不得自由发挥：
   - `实景空间型` → 上排三机位（主视角 / 反打 180° / 侧向 90°）+ 下排居中俯视平面布局图
   - `抽象舞台型` → 主视角 + 反向机位（**不出俯视布局图**）
5. **这不是九宫格。** 无分格线、无边框、无 grid、无漫画分镜结构；各视图仅靠均匀留白分隔。
6. **③ 段只允许一段 prompt**，风格由唯一风格串统一决定；不再有「日常档 / 写实档」双块。
7. **锁定的空间属性任何情况下都不得改变**：空间结构 · 固定陈设位置 · 材质 · 光源方位与时相 · 色彩基调。
8. **禁止把写实照片风当风格用。** 风格串只能取 `素材/画风/画风档位串.md` 的**唯一风格串**；禁止作为**正向描述**出现 `photorealistic / live-action / sequence photography / CGI / 3D render`（Negative 段中作为否定词的 `no photorealistic or live-action rendering`、反 3D 负向词表各项属例外，必须保留）。
9. **禁止把 8K 当硬约束。** 只写 `high detail`。
10. **固定陈设只取锚点表登记的**，不得加戏。

## 工作流

### 1 解析调用参数

调用形态（`/skill:location-sheet` 后的参数）：

| 输入 | 行为 |
|---|---|
| `跨界拳馆训练区` | 直接生成 → `素材/场地/跨界拳馆训练区.md` |
| `EP1` | **列出** EP1 全部场地与各自 `ref:` 状态，等使用者选择。**不得自行替选** |
| 无参数 | 扫描场地锚点表 + `剧本/EP/*.md`，列出「有出场但 `ref:` 为未生成」的场地 |
| `档=日常` / `档=写实`（**已作废**） | 传入即忽略。全项目已合并为单一 2D 画风，③ 段只有一段 |
| `比例=3:2` | 覆盖默认 16:9 横版 |
| `回写` | 生成后直接回写锚点表 `ref:` 与 `素材/场地/索引.md`；**默认只产交付文件 + 主动询问** |

- 场地名以锚点表 `### <中文名>` 小节标题匹配；**场地名 = 文件名**。
- 场地在锚点表中不存在 → 按锚点表「格式规范」现场生成锚点，并在交付文件末尾**主动询问是否追加进锚点表**。

### 2 读取素材（必读）

1. `素材/画风/画风约束.md` → **唯一风格串**的**权威源**。
2. `素材/画风/画风档位串.md` → **唯一风格串** + 参考图上传策略（含「场地设定图暂不上传」）+ 反 3D 负向词表，**逐字引用**，不得改写。
3. `素材/场地/场地锚点表.md` → 空间锚定串、`type:` 与 `ref:` 状态。
4. `剧本/EP/*.md` + `剧本/大纲/*.md` → 场地语境与固定陈设依据（如「远角比斯基缠手带」「装备箱在场中央」）。

### 3 空间锚点复核

- 逐字段核对 `type / space / layout / material / light / props / palette`；缺字段现场补，并**询问是否回写锚点表**。
- **特别注意**：`layout:` 必须与剧本里出现过的机位描述逐条对齐（如 EP1 场景4「场地被中轴自然划为左右两半」、场景2「龙卷立于场地中央训练假人前」、场景5「角落哑铃杆」）。
- 补齐英文锚定串中缺失的具体信息（材质色相、陈设尺寸感、轴线走向）。
- 填写 **「各机位可见内容」** 专项表（主视角看到什么 / 反打看到什么 / 侧向看到什么 / 俯视图陈设方位），确保各视图互相吻合、不越轴。
- `抽象舞台型` 场地：`material / props` 极简，**不填俯视图行**。

### 4 判定场地类型与版式

| `type` | 版式 |
|---|---|
| `实景空间型` | 4 视图：上排三机位 + 下排居中俯视平面布局图 |
| `抽象舞台型` | 2 视图：主视角 + 反向机位（`Bottom row` 整行删除） |

### 5 生成交付文件

路径：`素材/场地/<场地名>.md`（`素材/场地/` 目录首次运行时创建）。

结构模板见 `assets/location-sheet-template.md` 与 `assets/location-sheet-prompt-template.md`，四段固定顺序：

1. **元信息**
   场地 / 英文名 / 场地类型 / 比例 / 版式 / 轴线约定 / 固定陈设 / 光源方位 / 空场声明 / **上传策略（本次出图阶段不上传本场地设定图）** / 输出路径 / 生成状态
2. **空间锚点复核表**（九个字段 + 各机位可见内容专项表）
3. **英文 Prompt**（**单一代码块** `## ③ 英文 Prompt`；已无档位，不得出现 ③-A/③-B 双块）
4. **自检清单**（15 项）

### 6 回写登记

询问后（或带 `回写` 参数）执行：

1. 锚点表 `ref:` 字段 → `日常=<路径>；写实=<路径>`
2. `素材/场地/索引.md` 对应行状态更新
3. 若该场地已被已有分镜引用，把对应分镜 ④ 自检里的 `参考图风险` 从「中」降为「低」

### 7 自检（必须执行，结果写进交付文件第 ④ 段）

逐项写出 `[x]`/`[ ]` 与依据：

1. **单一场地**：全图只画 1 个场地空间，无跨场景拼贴
2. **版式**：实景空间型 = 上排三机位 + 下排居中俯视布局图；抽象舞台型 = 主视角 + 反向机位（按例外处理）
3. **空场**：画面内无任何角色 / 人形剪影 / 群众 / 宠物（prompt 与 Negative 双处声明）
4. **画面零文字**：无机位标签、无箭头、无尺寸线、无编号、无水印、无签名
5. **无分格线 / 边框 / grid**：各视图仅靠均匀留白分隔
6. **机位自洽（不越轴）**：三机位的轴线、入口方位、纵深关系互相一致
7. **俯视布局图与三机位一致**：固定陈设位置与三机位所见逐件吻合（抽象舞台型不适用）
8. **光照一致性**：光源方位与时相在全部视图里相同；俯视图以阴影方向表达同一光位
9. **锚点字段完整**：九个字段逐项落地，无「只剩场地名」
10. **③ 段为单一块**：只有一个代码块，未出现 ③-A/③-B 双块或第二个风格串
11. **风格切换未改空间结构**：材质 / 布局 / 光位 / 配色锁定不变
12. **比例声明**：全图 16:9（或调用参数指定值），只声明一次，未与九宫格 9:16 混写
13. **Negative 段完整照抄**（**含反 3D 负向词表**），未增删
14. **禁用词检查**：无 `photorealistic / live-action / sequence photography / CGI / 3D render / 8K`（Negative 否定形式除外）
15. **场地参考图登记已回写**锚点表 `ref:` 与 `素材/场地/索引.md`（若使用者确认）

末尾追加：
```
风格风险：低 / 中（无画风参考图）
参考图风险：低（本文件即场地参考图源头）
```

## 反模式黑名单（禁止回归）

| # | 反模式 | 处理 |
|---|---|---|
| 1 | 场地参考图里画上角色 / 人形剪影 | 铁律 2；进 Negative（`no characters / no people / no human silhouettes`） |
| 2 | 画面里标 `main view` / `reverse` 机位标签 | 铁律 3；机位映射写进 ① 元信息与 ② 各机位可见内容表 |
| 3 | 画成九宫格 / 漫画分镜 | 进 Negative（`no panel borders / no manga panel layout / no storyboard`） |
| 4 | 三机位各自合理但互相不吻合（越轴 / 陈设位移） | ② 各机位可见内容表 + prompt `Spatial lock:` + 自检 6/7 |
| 5 | 俯视布局图与三机位矛盾 | prompt 要求俯视图表达同一 layout + 自检 7 |
| 6 | 抽象舞台型硬出俯视布局图 | 铁律 4 例外规则 + 自检 2 |
| 7 | 重新引入第二段 prompt / 第二个风格串 | 铁律 6 + 自检 10 |
| 8 | 给空场地加氛围道具「让图好看」 | 铁律 10 + 自检 9 |
| 9 | 场地参考图比例写成 9:16 | 自检 12（场地参考图默认 16:9 横版） |
| 10 | 把参考图路径写进 prompt 正文 | 禁止；路径只进交付文件元信息（人可读区） |

## 常见借口对照

| 借口 | 为什么无效 |
|---|---|
| 「空场地太空，加个人物好看点」 | 有角色的参考图会污染角色锚定（同一角色在不同图里长相会漂），且违反「角色参考图负责角色」的分工。必须是空场。 |
| 「场地设定图能帮模型定空间，还是传吧」 | 现有两张场地设定图是 CG 渲染空间图（体积光 + 环境光遮蔽 + 地板反射），会把整格画面拉向 CG，**暂不进入出图链路**；空间用场地锚定串锁。 |
| 「俯视图省掉，三机位够了」 | EP1 场景4 的「场地被中轴划为左右两半」正是靠俯视才能钉死；三机位各看一层皮，判断不了相对位置。 |
| 「黑舞台也做俯视图更统一」 | 纯黑虚空没有地面也没有陈设，俯视图无信息量且会诱导模型虚构出地面与墙体。 |
| 「双档各写各的更灵活」 | 全项目已合并为单一 2D 画风，第二档已作废。③ 段只允许一段 prompt。 |
| 「场地名够模型认出来了」 | 模型对「拳馆」有大量先验，会给一个通用健身房；`Spatial lock:` 是唯一有效抓手。 |
| 「训练假人是角色，不该出现在场地图里」 | 训练假人是**固定陈设**，其本站位正是空间锚定的一部分。角色指「有叙事的出场人物」，陈设不算。 |
