## ④ 自检清单

1–17 固定项，逐项 `[x]` / `[ ]` + 依据；场景特有检查追加为 18+。

- [ ] 1. 9 格等大、硬边框、无中间大图 / 无漫画式不规则分格
- [ ] 2. 比例声明自洽：总图比例 = 单格比例（未声明为两个不同值）
- [ ] 3. 每格内部为完整构图（不是被裁切的碎片）
- [ ] 4. 远景 / 中景 / 近景 / 特写各 ≥ 1 格；相邻格不同景别或不同角度
- [ ] 5. 全局光源方位在 9 格中一致；道具状态连续
- [ ] 6. 全部出镜角色都有完整锚定串，无「只剩角色名」
- [ ] 7. Style 段只有一行、逐字取自唯一风格串，未自创 / 未改写 / 未拆成九行
- [ ] 8. 无文字 / 气泡 / 镜号 / 水印
- [ ] 9. Negative 段完整照抄（含反 3D 负向词表），未增删
- [ ] 10. 幻视/硬切（若存在）占相邻两格且已标注
- [ ] 11. 分屏网格保护：正误对照分屏的二分发生在单格内部，9 格等大硬网格未破
- [ ] 12. 出镜角色参考图齐备性：本场出镜角色均有参考图，或已标注 `未生成（缺）`
- [ ] 13. 参考图策略正确：风格参考图行已登记 `素材/画风/画风参考.png` 并标注必传；场地行不含 `.png` 路径
- [ ] 14. 场地登记齐备性：本场所用场地已在场地行分别列明并注明镜号（无路径）；**③ 段含 `Location:` 行且逐字取自场地锚点表英文锚定串**
- [ ] 15. 跨空间场景已在场地行分别列明并注明镜号（无路径），未串档
- [ ] 16. Negative 含反 3D 负向词表，逐字照抄，未增删
- [ ] 17. `Consistency:` 含体型比例锁定语：各 IP 角色保留自身原体型比例，未被归一化、未被改成 chibi
- [ ] 18. `Location:` 行逐字取自 `素材/场地/场地锚点表.md` 对应场地英文锚定串，未自创；结尾含 `This location is authoritative…` 句；一场跨两空间已按格区间分别标注
