# 九宫格分镜提示词生成

## 概述

把一个**剧本场景**（如 EP1《场景3 | 埼玉登场 · 画风切写实》）转成一份 **3×3 九宫格分镜交付文件**，包含：

1. 元信息（场景 / 时间 / 在场角色 / 比例 / 全局光位 / 参考图登记）
2. 中文九格分镜表（8 列）
3. 可直接复制的**英文九宫格生图 Prompt**
4. 自检清单

**本 skill 不出图。** 只产出提示词文本，出图由使用者把它粘贴到 即梦 / Midjourney / GPT / Nano Banana 等工具完成。

> **本项目的出图执行器**：`.pi/skills/image-gen/`。它直接读本 skill 产出的九宫格交付文件，自动抽第 ③ 段 prompt 与元信息里登记的参考图（风格图 + 角色图）同批提交给 tokenflux 出图，输出到同目录同名 `.png`，并把「出图状态」写入元信息表。手工粘贴到生图工具仍然可用——`image-gen` 是可选路径，不是替代。

**开始时宣布：** 「我正在使用 grid-storyboard 技能生成九宫格分镜提示词。」

---

## 铁律（违反即失败）

1. **一致性 > 镜头语言自由度。** 当"镜头更花哨"与"角色/空间/光位一致"冲突时，牺牲镜头变化。
2. **比例声明：总图比例 = 单格比例。** 3×3 均分下二者必然相等，**不得声明为两个不同值**。
3. **9 格等大、硬边框。** 严禁中间大图、不规则漫画分格、合并格、缺格。
4. **景别不与镜号绑定。** 镜号只表达叙事功能（见「4 九格编排」），景别由内容决定。
5. **角色必须写成完整锚定串。** 只写角色名/IP 名视为失败。
6. **空间结构以场地锚点表为准。** 场景空间结构 · 光源方位与时相 · 整体色彩基调 · 固定陈设站位以 `素材/场地/场地锚点表.md` 为准，不得在分镜里另起一套。
7. **文字一律不进画面。** 字卡、镜号、台词、气泡均由后期叠加；生图 prompt 必须含 `No text`。
8. **禁止把写实照片风当风格用。** 正面风格串只能取 `素材/画风/画风档位串.md` 的**唯一风格串**，禁止作为**正向描述**出现 `photorealistic / live-action / sequence photography / CGI / 3D render`。（Negative 段中作为否定词的 `no photorealistic or live-action rendering`、反 3D 负向词表各项属例外，必须保留）
9. **只有一个风格串，只写一行 `Style:`。** 全项目已合并为单一 2D 画风，禁止自创 / 改写风格串，禁止把 `Style:` 拆成九行 `Style — Panel N:`。
10. **场地设定图暂不进入出图链路。** 元信息的**场地行不得出现 `.png` 路径**（否则会被 `image-gen` 自动上传，而现有场地设定图是 CG 渲染空间图，会把画面拉向 3D）。空间以场地锚点表英文布局串 + `layout / light / palette` 锁定。
11. **空间锚点必须进 prompt。** 因场地设定图已撒离，③ 段**必须**含 `Location:` 行，逐字取 `素材/场地/场地锚点表.md` 的英文锚定串。**漏写即空间漂移**（模型会退回「木地板 + 擂台 + 沙袋」的通用健身房先验，与锚点表蓝灰拼缝地垫冲突）。
12. **`Consistency:` 段必须含体型比例锁定语。** 各 IP 角色保留自身原体型比例，只统一渲染风格；禁止把 Q 版角色归一化、禁止改成 chibi。
13. **禁止把 8K 当硬约束。** 只写 `high detail`。

## 工作流

### 1 解析调用参数

调用形态（`/skill:grid-storyboard` 后的参数）：

| 输入 | 行为 |
|---|---|
| `EP1 场景2` | 直接生成 → `分镜/EP1/EP1-场景2-九宫格.md` |
| `EP1`（无场景） | **列出** EP1 全部场景清单（编号 + 标题 + 时间码 + 在场角色），等使用者选择。**不得自行替选** |
| 无参数 | 扫描 `剧本/EP/*.md`：只有 1 个文件则默认该 EP 并列场景；多个则先列 EP 再列场景 |
| 附带比例（如 `16:9`） | 覆盖默认比例 9:16 |
| `写实格=` / `全日常`（**已作废**） | 传入即忽略。全项目已合并为单一 2D 画风，已无档位可切 |

- EP 编号从文件名 `EP<n>_` 解析，**保留原编号写法**（`EP1` / `EP10`）。
- 场景编号匹配 `## 场景N | <标题> (时间码)` 小节；场景标题若含 `|`，取 `## 场景N` 后、`(` 前的全部文本。

### 2 读取素材与剧本

1. **必读** 项目根 `素材/画风/画风约束.md` → 原文即**唯一风格串**（全项目唯一档）。
2. **登记风格参考图** `素材/画风/画风参考.png`：不解析图片内容，只在输出的元信息中登记「本场景出图时**必传**该参考图」（它是唯一且必传的风格锚点）。
   - 文件**缺失**时：降级为纯文字锚点，并在「④ 自检清单」标注 `风格风险：中（无画风参考图）`。
3. **读取角色锚点表** `素材/角色/角色锚点表.md`（项目级共享资产）。
4. **登记角色参考图**：查锚点表各角色的 `ref:` 字段（已为单一值），把本场景出镜角色登记进元信息。
   - 角色取该场**实际出镜**者，**背景剪影角色也要列**（一致性同样重要）
   - 角色仅以头像图标 / 道具形态出镜 → 写 `不适用（仅头像图标形态）`
   - 参考图缺失 → 写 `未生成（缺）`，并在「④ 自检清单」追加 `参考图风险：中（角色 X 无参考图）`
   - **路径只进元信息（人可读区），绝不进 prompt 正文**（反模式 #4）
   - 若出镜角色 `ref:` 为「未生成」：**主动提示**使用者可先用 `character-sheet` 技能补出参考图
5. **读取场地锚点表** `素材/场地/场地锚点表.md`（项目级共享资产），把该场地的 `layout / light / palette` 三项**作为分镜的硬约束**，直接对齐：
   - 分镜表「续接锚点」列的「光源方位一致」「180° 轴线一致」与「道具状态连续（陈设位置）」
   - 元信息的「全局光源方位」与「场景道具锚点」字段
   - `layout:` 里的固定陈设站位（如「训练假人立于中场偏后」「装备箱位于场地中央一侧」「远角为缠手带角落」）必须与分镜的机位描述相容，不得自相矛盾
6. **登记场地（名字进元信息，锚定串进 prompt）**：查场地锚点表各场地的 `layout / light / palette` 与**英文锚定串**。
   - **元信息场地行**：只登记场地名与镜号，**禁止出现 `.png` 路径**（铁律 10）
   - **prompt 的 `Location:` 行**：逐字取锚定串写进去（铁律 11）；一场跨两个空间 → 按格区间分别列出
   - 场地取该场**实际发生的空间**；**一场跨两个空间 → 两个都列并注明镜号**（如 EP1 场景2：镜01 片头黑舞台、镜03 起跨界拳馆训练区）
   - **场地行禁止出现 `.png` 路径**（铁律 10）：场地设定图暂不上传，空间以锚点表英文布局串 + `layout / light / palette` 锁定
   - 若场地 `ref:` 为「未生成」：**主动提示**使用者可先用 `location-sheet` 技能补出参考图
7. **解析目标场景**：抽取 `[画面]` / `[音效]` / `[字卡浮现]` / `[画风切换…]` / 角色台词，归一成一条**事件链**：
   - 时间、地点、在场角色、动作相位、镜头内可见道具、道具状态变化（如"哑铃杆被捏弯"）。
8. **确定角色名单**：
   - **主体角色**：有台词、或 `[画面]` 明确点名的角色。
   - **背景剪影角色**：仅用于说明空间关系，取 ≥ 1 个，不参与主叙事。
   - 出现锚点表中缺失的角色 → 按「6 角色锚点规范」现场生成，并在交付末尾**主动询问是否追加进锚点表**。

### 3 风格取值（唯一风格串）

**只有一个风格档。** 全项目统一为 `素材/画风/画风档位串.md` 的**唯一风格串**——即 `素材/画风/画风参考.png` 的文字化描述。

- 九宫格 ③ 段只写**一行** `Style: <唯一风格串>`，禁止拆成九行 `Style — Panel N:`。
- 风格串**逐字**取 `素材/画风/画风档位串.md`，禁止自创 / 改写 / 精简。
- 九宫格 ③ 段必须含 **`Location:` 行**（场地锚定串逐字取自场地锚点表），否则空间锚点为空。
- 剧本里的 `[画风切换为写实线条]` 标记**已作废**：技能识别该标记但**忽略**，不再据此切档（详见 `素材/画风/画风档位串.md`「历史沿革」）。
- 调用参数 `写实格=` / `全日常` **已作废**，传入即忽略。

**锁定属性（任何情况下都不得改变）**

> 脸型 · 发型 · 发色 · 瞳色 · 服装造型与配色 · 体型比例 · 场景空间结构 · 光源方位与时相 · 整体色彩基调

**其中「场景空间结构 · 光源方位与时相 · 整体色彩基调」三项以 `素材/场地/场地锚点表.md` 与场地锚定串为准，不得在分镜里另起一套。**

**只统一渲染风格，不统一体型比例。** 各 IP 角色保留自身原体型比例；`Consistency:` 段必须写入体型比例锁定语（见模板）。

**允许变化的只有**：动作 · 姿态 · 表情 · 景别 · 机位角度。

风格串原文见 `素材/画风/画风档位串.md`。

### 4 九格编排（核心）

#### 4.1 动作相位槽位（只表功能，不预设景别）

`起势 → 试探 → 升级 → 顶点 → 反应 → 转折 → 新信息 → 缓冲 → 收束`

#### 4.2 景别与角度硬性分布

- 9 格内**必须**至少各有 1 格：远景 / 中景 / 近景 / 特写
- 至少 3 格更换机位角度（正视 / 侧视 / 背视 / 过肩 / 内反打；俯仰仅允许轻微）
- **相邻两格不得同时相同景别且相同角度**
- 每格主体角色 ≤ 2 人，其余降为背景剪影

#### 4.3 续接锚点（每格必填一项，写出具体内容）

从下列五类中至少实现一类，填入分镜表「续接锚点」列：

1. **动作相位衔接**：上一格定格动作 = 下一格起始状态
2. **视线匹配**：A 格看向画外方向 = B 格主体视线反向
3. **180° 轴线一致**：同一场景内主轴线不得交叉
4. **光源方位一致**：全局光位写进元信息，9 格不得改变
5. **道具状态连续**：如 EP1 场景5 被捏弯的哑铃杆，后续格若出现须保持已弯状态

#### 4.4 节拍数量不匹配的兜底

- 节拍 **> 9**：合并相邻节拍，**优先保留动作相位完整性**，不得为塞内容牺牲连续性
- 节拍 **< 9**：用「反应镜头 / 环境空镜 / 道具特写」补足缓冲格，**不得重复同一格内容**

#### 4.5 特殊节拍的网格保护规则

- **正误对照分屏**（EP1 场景4；EP2/EP3/EP6/EP8 等）：在**单格内部**做左右二分构图（intra-panel split），**严禁**破坏 3×3 硬网格。
- **脑内幻视 → 硬切现实**（固定节拍 6a/6b）：必须占**相邻两格**分别承载，分镜表显式标注「6a 幻视」「6b 硬切」。幻视格允许夸张表现，但**角色锚点仍锁**。

### 5 生成交付文件

路径：`分镜/<EP>/<EP>-场景N-九宫格.md`（`分镜/` 目录首次运行时创建）。

结构模板见 `assets/storyboard-table-template.md` 与 `assets/grid-prompt-template.md`，四段固定顺序：

1. **元信息**
   EP / 场景号与标题 / 时间码 / 时间地点 / 在场角色（主体 vs 背景）/ 比例 / 全局光源方位 / **需同批上传的参考图（三行：风格 / 角色 / 场地）** / 事件链一句话

   （已删除 `风格档分布` 行——全项目单一风格档，无分布可言。）

   **参考图各行的填充规则**：
   - **风格行**：恒为 `素材/画风/画风参考.png`，标注**必传**。
   - **角色行**：列出镜角色的 `ref:` 路径（背景剪影角色也要列）；角色仅以头像图标 / 道具形态出镜 → 写 `不适用（仅头像图标形态）`
   - **场地行**：取该场**实际发生的空间**；一场跨越两个空间（如 EP1 场景2 的镜01 黑舞台 + 镜03 起拳馆）→ **两个都列**并注明镜号；**只写场地名，禁止写 `.png` 路径**（铁律 10），并注明「暂不上传」
   - 参考图缺失 → 写 `未生成（缺）`，并在「4 自检清单」汇入 `参考图风险` 行
   - **路径仍只登记在元信息（人可读区），绝不进 prompt 正文**
2. **中文九格分镜表**（7 列）

   | 镜号 | 景别 | 角度 | 画面内容 | 动作·情绪 | 续接锚点 | 角色锚点 |
   |---|---|---|---|---|---|---|

3. **最终英文九宫格 Prompt**（单个 ```text 代码块，可整段全选复制）
4. **自检清单**（执行「7 自检」并写出勾选结果）

### 6 角色锚点规范

写入 `素材/角色/角色锚点表.md`，强制格式（字段顺序固定）：

```
<中文名> | <IP 官方英文名> | hair: <发型+发色> | eyes: <瞳色> | outfit: <服装+配色> | build: <体型+年龄感> | prop: <标志性道具> | ref: <路径或「未生成」>
```

- `ref:` 字段登记角色参考图路径；缺失写 `未生成`。参考图由 `character-sheet` 技能产出，见 `素材/角色/索引.md`。
- **禁止只写 IP 名或角色名**
- 同时给中文名与英文名；生图 prompt 正文一律用**英文锚定串**
- 缺失角色的锚点现场生成后，**主动询问是否追加进锚点表**，以便 EP2 起（军子、君麻吕、春丽…）跨集复用

### 7 自检（必须执行，结果写进交付文件第 ④ 段）

1–15 为固定项，逐项写出 `[x]`/`[ ]` 与依据；场景特有的检查可按需追加为 16+。

1. 9 格等大、硬边框、无中间大图 / 无漫画式不规则分格
2. 比例声明自洽：**总图比例 = 单格比例**，未声明为两个不同值
3. 每格内部为完整构图（不是被裁切的碎片）
4. 远景 / 中景 / 近景 / 特写各 ≥ 1 格；相邻格不同景别或不同角度
5. 全局光源方位在 9 格中一致；道具状态连续
6. 全部出镜角色都有完整锚定串，无「只剩角色名」
7. **Style 段只有一行**、逐字取自 `素材/画风/画风档位串.md` 唯一风格串，未自创 / 未改写 / 未拆成九行
8. 无文字 / 气泡 / 镜号 / 水印
9. Negative 段完整照抄（**含反 3D 负向词表**），未增删
10. 幻视/硬切（若存在）占相邻两格且已标注
11. **分屏网格保护**：若场景含正误对照分屏，确认二分发生在单格内部，9 格等大硬网格未破
12. **出镜角色参考图齐备性**：本场出镜角色均有参考图，或已在元信息标注 `未生成（缺）`
13. **参考图策略正确**：风格参考图行已登记 `素材/画风/画风参考.png` 并标注必传；**场地行不含 `.png` 路径**
14. **场地登记齐备性**：本场所用场地已在场地行分别列明并注明镜号（无路径）；**③ 段含 `Location:` 行且逐字取自场地锚点表英文锚定串**
15. **跨空间场景**已在场地行分别列明并注明镜号（无路径），未串档
16. **Negative 含反 3D 负向词表**，逐字照抄，未增删
17. **`Consistency:` 含体型比例锁定语**：各 IP 角色保留自身原体型比例，未被归一化为标准动漫头身比、未被改成 chibi

末尾固定追加两行风险（紧接自检清单）：

`风格风险：低 / 中（无画风参考图）`
`参考图风险：低 / 中（角色 X、Y 无参考图）`

## 反模式黑名单（禁止回归）

原始三份提示词的缺陷，已固化禁止：

| # | 反模式 | 处理 |
|---|---|---|
| 1 | 风格串写 `photorealistic / sequence photography` | 禁用；风格串只能取 `素材/画风/画风档位串.md` |
| 2 | 景别与编号绑定（`Panel 4: close-up`） | 禁用；槽位只表功能 |
| 3 | 输出形态脚踩两条船（既要文本又要图） | 本 skill **只产文本 prompt** |
| 4 | prompt 正文里写「图1是什么角色,图2是…」 | 禁用；参考图登记只进元信息（人可读区） |
| 5 | 把 `8K` 当硬约束 | 只写 `high detail`；多数模型 ≤2048px，3×3 后单格细节有限，建议工具侧开高清或对重点格另出单格图 |
| 6 | 中间大图 / 不规则分镜 / 格子大小不一 | 进 Negative + 自检 1 |
| 7 | 只写 IP 名不写外观锚点 | 进「6 角色锚点规范」强制格式 |
| 8 | 画面上出现字卡 / 镜号 / 气泡 | 字卡后期叠加，一律不进画面 |
| 9 | 无续接语法只靠形容词描述「连续性」 | 进「4.3 续接锚点」强制列 |
| 10 | 无优先级声明 | 一致性 > 镜头语言自由度 |
| 11 | 同一场景内空间结构 / 陈设位置跨格漂移 | 进「场地锚点表」；分镜表「续接锚点」列须写明 180° 轴线与陈设位置 |
| 12 | 重新引入第二个风格串 / 写九行 `Style — Panel N:` | 铁律 9；全项目单一风格档，只写一行 `Style:` |
| 13 | 把场地设定图写进元信息场地行（会被 `image-gen` 自动上传） | 铁律 10；现有场地设定图是 CG 渲染空间图，会注入 3D 感 |
| 14 | 把 Q 版角色体型归一化 / 改成 chibi | 铁律 12 + 自检 17；只统一渲染风格，不统一体型比例 |
| 15 | 九宫格 prompt 漏写 `Location:` 行 | 铁律 11 + 自检 14；空间锚点为空时模型会退回「木地板 + 擂台 + 沙袋」通用健身房先验 |

## 常见借口对照

| 借口 | 为什么无效 |
|---|---|
| 「场景太短，凑不满 9 格就重复用两格」 | 重复格会让九宫格变成六格，破坏叙事推进。必须用空镜/反应/道具特写补足。 |
| 「让 Panel 4 固定是特写更好懂」 | 这会使景别与内容脱钩，与「按剧情自动选景别」的需求直接矛盾。 |
| 「写实档可以直接写 photorealistic」 | 项目画风是 2D 动画 key-visual；已合并为单一风格串，且风格串里不得出现 `photorealistic / CGI / 3D render` 类正向词。 |
| 「比例写两个更保险」 | 3×3 均分下二者必然相等，写两个不同值会让模型误以为要分形不同比例，反而引入矛盾。 |
| 「角色名够模型认出来了」 | 跨 IP 混编时模型会自由发挥或角色漂移；锚定串是唯一有效抓手。角色参考图（`character-sheet` 产出）是图片锚点，比文字锚点更强，优先级更高。 |
| 「场地设定图能帮模型定空间，还是传吧」 | 现有两张场地设定图是 **CG 渲染空间图**（体积光 + 环境光遮蔽 + 地板反射），会把整格画面拉向 CG。空间用**场地锚定串写进 prompt 的 `Location:` 行**锁定。 |
| 「剧本写了 `[画风切换为写实线条]`，得按它切档」 | 该标记**已作废**；全项目已合并为单一 2D 画风，技能识别但**忽略**（见 `素材/画风/画风档位串.md`「历史沿革」）。 |
