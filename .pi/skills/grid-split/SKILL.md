# 九宫格切图（grid-split）

## 概述

把 `image-gen` 产出的 **3×3 九宫格合成图** 切回 **9 张等大单格图**，供视频剪辑 / 重点格重绘 / 单格复用。

```
剧本/EP/*.md
   └─ grid-storyboard ─► 分镜/<EP>/<EP>-场景N-九宫格.md
         └─ image-gen ─► 分镜/<EP>/<EP>-场景N-九宫格.png
               └─ grid-split ─► 分镜/<EP>/<EP>-场景N-九宫格/镜头01.png … 镜头09.png
```

**第三个技能都写着「不出图/只产 prompt」，image-gen 是执行器，本技能是它之后的那一步：把合成图拆开。**

**核心价值**：

1. **自动裁白缝** —— 九宫格格间有细白缝、外边有描边；直接 `W/3` 硬切每张都会残留白边。本技能自动识别缝带并裁到内容边缘。
2. **按镜号命名** —— 给 `.md` 交付文件时，读 ② 分镜表的「镜号」列，产出 `镜头01.png`…，与分镜表、prompt 的 `Panel N` 一一对应，而不是无意义的 `1.png`。
3. **自动反查源图** —— 只需指向交付文件 `.md`，技能自己从「出图状态」行找源 `.png`，并回写「切分状态」。

**本技能只做裁切，不生成、不重绘、不缩放内容。**

**开始时宣布：** 「我正在使用 grid-split 技能切分九宫格。」

---

## 铁律（违反即失败）

1. **只裁不画。** 输出像素必须逐字节来自源图，禁止缩放、重绘、加边框、加滤镜、有损压缩。只允许「裁剪 + 无损 PNG 重编码」。
2. **不覆盖已有产物。** 输出目录已有同名文件时拒绝执行（exit 2），必须显式 `--force`。
3. **检测失败必须上报，不得静默当成功。** 某个边界没检出白缝 → 回退精确三等分**并记 warning**；尺寸偏差超容差 → 记 warning；一律如实写进报告与 `index.json`。
4. **只处理 PNG。** 非 PNG / 隔行 / 16-bit 一律明确报错（exit 3），禁止静默转码或强切。
5. **先 dry-run 再切。** 不熟悉的图先 `--dry-run` 核对缝带与 9 个矩形；确认后再切。
6. **回写只改一行。** 只动 `切分状态` 行；其余字节（含 CRLF/LF、UTF-8 BOM）逐字不变。
7. **报告必须含落盘校验 + 目视校验。** 不能只看脚本打印的尺寸：Agent 必须真的把 2–3 张产物读出来看，确认是完整单格、无白边、无内容被切。

## 调用形态

```bash
S=.pi/skills/grid-split/scripts/split_grid.mjs

# 推荐：给交付文件 .md —— 自动定位源图 + 按镜号命名 + 回写切分状态
node $S 分镜/EP1/EP1-场景2-九宫格.md
# → 分镜/EP1/EP1-场景2-九宫格/镜头01.png … 镜头09.png + index.json

# 先看不切（任何不熟悉的图都先 dry-run 一次）
node $S 分镜/EP1/EP1-场景2-九宫格.md --dry-run

# 裸 PNG 直切 —— 无镜号，回退 panel-1.png … panel-9.png
node $S 分镜/EP1/EP1-场景1-九宫格.png

# 源图格子宽窄不均、检测结果不理想时：强制精确三等分
node $S 分镜/EP1/EP1-场景1-九宫格.png --fixed --out-dir tmp/s1-fixed

# 统一四边内缩 6px 去白缝
node $S 分镜/EP1/EP1-场景1-九宫格.png --trim-px 6

# 覆盖重切
node $S 分镜/EP1/EP1-场景2-九宫格.md --force

# 机器可读
node $S 分镜/EP1/EP1-场景2-九宫格.md --json
```

完整参数表、退出码、语义见 `references/cli.md`；脚本自带 `--help`，是所有参数的权威来源。算法细节（PNG 编解码约束、白缝检测）见 `references/method.md`。

### 参数速查

| 场景 | 参数 |
|---|---|
| 指定输出目录 | `--out-dir 分镜/EP1/切图` |
| 覆盖重切 | `--force` |
| 关闭自动裁缝（精确三等分） | `--fixed` |
| 固定四边内缩 N 像素 | `--trim-px 6` |
| 改网格 | `--rows 4 --cols 3` |
| 调白缝判定 | `--gutter-threshold 240` / `--gutter-tolerance 8` |
| 不写清单 / 不回写 | `--no-manifest` / `--no-writeback` |
| 只看不切 | `--dry-run` |
| 机器可读 | `--json` |

## 工作流

### 1 确认切分对象

| 输入 | 行为 |
|---|---|
| `<交付文件.md>` | 从「出图状态」行定位源 `.png`；读 ② 表镜号；可回写。**首选** |
| `<九宫格.png>` | 直接切；命名 `panel-N`；无回写 |
| `/skill:grid-split EP1 场景2` | 先**列出** `分镜/EP1/` 下已出图的九宫格（`.png` 存在者），等使用者确认。**不得自行替选** |
| 无参数 | 扫描 `分镜/**/*-九宫格.png`，列出「已出图但尚未切分（无同名目录 / 无 `切分状态` 行）」的，等使用者选择 |

**一次切一张，不批量。** 逐张核对缝带与产物。

### 2 先 dry-run，再切

**这是唯一的手工前置步骤，不是可选项。** 未 dry-run 核对过的图不得直接切。

dry-run 要核对 4 项：

1. `源图` 尺寸与「比例」行自洽（如 9:16 → 约 1008×1792）
2. `竖缝带 / 横缝带` 落在预期的 `W/3`、`2W/3` 附近（偏差过大 → 可能是误检，改 `--fixed` 或调阈值）
3. 9 个矩形尺寸互差 ≤ 数像素、无 0 或负值
4. `输出目录 / 文件名` 与预期一致（`.md` 输入应为镜号）

任何一项不符 → 停下，报告差异，不要「先切了再说」。

### 3 切分

```bash
node .pi/skills/grid-split/scripts/split_grid.mjs <输入> [选项]
```

### 4 校验落盘 + 目视

脚本已内置落盘校验（文件存在 / 字节 > 0 / 像素尺寸）。**Agent 必须如实转述脚本报告**，并额外做脚本无法判断的一件事：**读出 2–3 张产物目视确认**——

- 是完整的单格画面（不是被裁掉一角的碎片）
- 四边无白缝 / 无描边残留
- 内容与分镜表该镜号描述一致

发现问题如实报告，不要因为「脚本 exit 0」就说成功。产物尺寸与源图不符（宽窄不均）时，说明源图本身不规整，脚本会给出 warning，照抄。

### 5 回写

`.md` 输入时脚本自动回写 `切分状态` 行（不存在则在参考图行后新增）：

| 值 |
|---|
| `已切分 · <输出目录>/ · 9 张 · YYYY-MM-DD HH:mm` |

回写**只允许改这一行**，其余字节不变。回写失败不影响图片，但必须报告。`--dry-run` / `--no-writeback` 完全不写。

### 6 输出报告

见 `assets/split-report-template.md`。报告须含：源图与尺寸 / 切分模式 / 缝带与裁切值 / 9 张落盘路径+字节+尺寸 / 清单路径 / 回写位置 / 警告 / **目视结论**。

## 切分模式

| 模式 | 触发 | 行为 | 何时用 |
|---|---|---|---|
| `auto-trim`（默认） | 无 | 逐边界检测近白缝带并裁到内容；未检出则回退精确三等分 + warning | 常规九宫格（有细白缝） |
| `fixed` | `--fixed` | 精确 `round(W·k/3)` 均分，不裁缝 | 源图格子宽窄不均、或想保留原始缝隙/便于对照 |
| `trim-px` | `--trim-px N` | 每格四边统一内缩 N 像素 | 缝宽已知且一致、要确定性结果 |

**白缝判定**（`auto-trim`）：某列/行若「近单色」（通道极差 ≤ `--gutter-tolerance`，默认 12）且「近白」（平均亮度 ≥ `--gutter-threshold`，默认 235），判为缝。只在期望边界 `±max(8, 3%)` 窗口内、长度 `≤ max(6, 4%)` 的连续 run 才算缝，避免把面板内大片白墙误判。详见 `references/method.md`。

**面板顺序固定行优先**：Panel1 = 左上 … Panel9 = 右下，与本项目九宫格 prompt 的 `Panel N` 一致。

## 自检清单（写入报告）

- [ ] 1. 输入解析正确：`.md` 定位到源 `.png`（或直接传入 `.png`）
- [ ] 2. 解码成功；源图尺寸与 3×3（或 `--rows/--cols`）假设自洽
- [ ] 3. 裁缝结果合理：缝带落在预期边界附近；9 格尺寸互差在容差内（超差已记 warning）
- [ ] 4. 9 张文件存在、字节 > 0、能读出像素尺寸
- [ ] 5. 命名正确：`.md` 输入用 ② 表镜号，裸 PNG 用 `panel-N`；与分镜表一一对应
- [ ] 6. 未覆盖旧图（除 `--force`）
- [ ] 7. 回写只改一行（其余字节不变）
- [ ] 8. `index.json` 与产物一致
- [ ] 9. **目视**：至少 2–3 张是完整单格、无白边、内容与镜号描述相符
- [ ] 10. 警告已如实转述，未美化

## 反模式黑名单（禁止回归）

| # | 反模式 | 处理 |
|---|---|---|
| 1 | 不 dry-run 直接切 | 工作流 2 拦截；误检会一次产 9 张坏图 |
| 2 | 把「未检出白缝」静默当成功 | 铁律 3；必须回退精确三等分 + warning |
| 3 | 直接 `W/3` 硬切不裁缝 | 产物四边残留白缝；用默认 `auto-trim` |
| 4 | 自动加 `--force` 重跑 | 铁律 2；覆盖必须由使用者决定 |
| 5 | 对非 PNG / 隔行 / 16-bit 静默产出 | 铁律 4；exit 3 + 明确提示 |
| 6 | 缩放 / 重绘 / 压缩到有损 / 加边框 | 铁律 1；只裁不画 |
| 7 | 只凭 exit 0 宣布成功 | 铁律 7；必须落盘校验 + 目视 |
| 8 | 回写改动多行 / 重排表格 | 铁律 6；只改 `切分状态` 一行 |
| 9 | 一次性把 `分镜/EP1/` 全部切分 | 一次一张，逐张核对 |
| 10 | 把源图格子宽窄不均当「工具 bug」 | 那是生成结果本身的偏差；脚本已 warning，可用 `--fixed` 得到等分 |

## 常见借口对照

| 借口 | 为什么无效 |
|---|---|
| 「`W/3` 切出来也能用，何必检测缝」 | 每张四边都会留一条白边，剪辑时更麻烦；默认 `auto-trim` 就是为消掉它。 |
| 「检测没找到缝，我就当没缝精确切」 | 那正是「静默降级」。脚本会回退并 warning，使用者才知道该改 `--fixed` 或调阈值。 |
| 「源图是 JPEG，我帮忙转一下再切」 | 转码会引入有损/色偏，破坏「只裁不画」。用 image-gen 重出为 PNG。 |
| 「9 格尺寸差了几像素，无所谓」 | 差几像素是正常的缝宽不均；差几十像素说明源图本身不规整——必须让使用者知道。 |
| 「已经 exit 0 了，肯定没问题」 | exit 0 只说明脚本跑通；画面是否完整必须目视确认。 |
| 「先把整个 EP 的九宫格都切了省事」 | 一次切 9 张，误检会连带 9 张坏图。逐张 dry-run + 目视。 |
