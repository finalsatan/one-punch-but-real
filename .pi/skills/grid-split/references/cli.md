# CLI 参考（split_grid.mjs）

> `node .pi/skills/grid-split/scripts/split_grid.mjs --help` 是权威来源；本文件解释**语义**与**典型用法**。
> 路径均为**相对当前工作目录（项目根）**解析。

---

## 1 输入

| 参数 | 语义 | 备注 |
|---|---|---|
| `<交付文件.md>`（位置参数） | 从「出图状态/生成状态」行反查源 `.png`；读 ② 分镜表「镜号」列命名；可回写「切分状态」 | **首选** |
| `<九宫格.png>`（位置参数） | 直接切分 | 命名回退 `panel-1.png` … `panel-9.png` |
| 无参数 / 多于 1 个 | 打印 `--help` 并 exit 2 | — |

### `.md` → 源图定位顺序

1. 在交付文件里找 `| 出图状态 |` 或 `| 生成状态 |` 或 `| 图片路径 |` 行，正则抽取 `…png` 路径
2. 依次尝试：`cwd` 相对 → `.md` 所在目录相对 → `.md` 同目录同名 `.png`
3. 全部失败 → exit 4，提示「先跑 image-gen 出图」

### `.md` → 镜号命名

定位表头含「镜号」的表格，按行取该列（跳过表头与分隔行），得到最多 9 个标签。不足则缺失格回退 `panel-N`，并记 warning。

---

## 2 输出

| 参数 | 语义 |
|---|---|
| `--out-dir <dir>` | 输出目录。省略时 = `<源图目录>/<源图去扩展名>/`（如 `分镜/EP1/EP1-场景2-九宫格/`） |
| `--force` | 允许覆盖已存在输出（默认**拒绝**，exit 2 并列出占用文件） |
| `--no-manifest` | 不写 `index.json` |
| `--no-writeback` | 不向 `.md` 回写「切分状态」 |

输出目录不存在会自动创建。写入是原子的（先写 `.part` 再 rename）。

**命名**：`.md` 输入 → ② 表镜号（`镜头01.png` …）；裸 `.png` 输入 → `panel-1.png` … `panel-9.png`。

**面板顺序**：行优先，Panel1 = 左上 … Panel9 = 右下。

---

## 3 切分模式

| 参数 | 语义 |
|---|---|
| （无） | `auto-trim`：逐边界检测近白缝带，裁到内容边缘；未检出则回退精确三等分 + warning |
| `--fixed` | 精确 `round(W·k/cols)` 均分，不裁缝（保留原始缝隙） |
| `--trim-px <n>` | 每格四边统一内缩 n 像素 |

`--fixed` 与 `--trim-px` **互斥**（同时给 → exit 2）。

| 参数 | 默认 | 语义 |
|---|---|---|
| `--rows <n>` | 3 | 网格行数（1..20） |
| `--cols <n>` | 3 | 网格列数（1..20） |

---

## 4 白缝检测调参

| 参数 | 默认 | 语义 |
|---|---|---|
| `--gutter-threshold <n>` | 235 | 「近白」亮度下限（0..255）。调**低**可吃掉偏灰的缝 |
| `--gutter-tolerance <n>` | 12 | 「近单色」通道极差上限。调**大**可容忍带噪/渐变的缝 |

判定：某列/行「近单色」（通道极差 ≤ tolerance）**且**「近白」（平均亮度 ≥ threshold）→ 判为缝。
只在期望边界 `±max(8, 3%)` 窗口内、长度 `≤ max(6, 4%)` 的连续 run 才算缝。详见 `method.md`。

---

## 5 诊断

| 参数 | 语义 |
|---|---|
| `--dry-run` | 打印源图信息 / 缝带 / 裁切值 / 9 个矩形 / 输出路径 / 会覆盖，**不写任何文件** |
| `--json` | 机器可读输出（结构与 `index.json` 同源） |
| `-h`, `--help` | 完整帮助 |

### `--dry-run` 输出字段

| 字段 | 用途 |
|---|---|
| `源图` | 确认 `.md → .png` 定位正确，尺寸与「比例」行自洽 |
| `切分模式` | `auto-trim` / `fixed` / `trim-px` |
| `外描边裁切` | 四边内缩像素（自动检测结果，或 `--trim-px` 值） |
| `竖缝带` / `横缝带` | 检测到的缝带（`x=333..335`）；未检出则显示单个期望坐标 |
| `输出目录` / 逐格 `文件名` | 命名是否正确（镜号 / `panel-N`） |
| `会覆盖` | 已存在目标（正式运行默认拒绝，需 `--force`） |

---

## 6 退出码

| 码 | 含义 |
|---|---|
| `0` | 成功 |
| `2` | 参数 / 解析错误（含输出已存在、`--fixed` 与 `--trim-px` 冲突、非法 `--rows/--cols`） |
| `3` | 图像编解码错误（非 PNG / 隔行 / 16-bit / 非法裁切矩形） |
| `4` | 输入缺失，或无法从 `.md` 定位源图 |

脚本会同时打印一行**提示**（`提示：…`），说明下一步该怎么做。

---

## 7 典型用法

```bash
S=.pi/skills/grid-split/scripts/split_grid.mjs

# 1. 切分前必做：dry-run 核对
node $S 分镜/EP1/EP1-场景2-九宫格.md --dry-run

# 2. 正式切分（产出 镜头01.png … 镜头09.png + index.json，并回写切分状态）
node $S 分镜/EP1/EP1-场景2-九宫格.md

# 3. 裸 PNG 直切
node $S 分镜/EP1/EP1-场景1-九宫格.png

# 4. 源图格子宽窄不均时强制等分
node $S 分镜/EP1/EP1-场景1-九宫格.png --fixed --out-dir tmp/s1-fixed

# 5. 已知缝宽，统一内缩
node $S 分镜/EP1/EP1-场景3-九宫格.png --trim-px 6

# 6. 覆盖重切
node $S 分镜/EP1/EP1-场景2-九宫格.md --force

# 7. CI / 脚本消费
node $S 分镜/EP1/EP1-场景2-九宫格.md --json

# 8. 非 3×3 网格
node $S 素材/画风/画风参考.png --rows 2 --cols 3
```

## 8 回写规则

仅 `.md` 输入时执行。

1. 找 `| 切分状态 |` 行 → **原地替换值**
2. 找不到 → 在 `出图状态` / `生成状态` / `需同批上传的参考图…` / `参考图…` 行**之后新增**
3. 都不匹配 → 不回写（报告里 `回写：未执行`）

写入值：`已切分 · <输出目录>/ · <张数> 张 · YYYY-MM-DD HH:mm`

**保证**：

- 只改这一行，文件其余字节逐字不变
- 保留原换行风格（CRLF/LF）与 UTF-8 BOM 状态
- 回写失败**不影响图片**，但会在报告中警告
- `--dry-run` / `--no-writeback` 完全不写

**不做的回写**（属上游技能职责）：

- `出图状态` 行 → `image-gen`
- 九宫格 ④ 段自检 / `参考图风险` → `grid-storyboard`
